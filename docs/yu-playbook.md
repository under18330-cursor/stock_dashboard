## 1. 他的決策流程

1. **景氣位階決定下多重**：信號燈藍燈、PMI < 50、領先指標 < 100 時才重倉；牛市第 3 年起轉保守。
2. **週乖離決定何時買**：週 KD 的 J 值 < 25 是中期回調買點，> 100 停止買入；月乖離回 0 軸才動用債券。
3. **情緒指標確認**：CNN 恐懼貪婪 < 40（< 20 極度恐慌）、VIX 飆高、AAII 看空 > 50%、台股融資維持率接近 150%。
4. **依跌幅分批**：每跌 5% 加碼一次，並預設一個「現金投完」的目標跌幅。
5. **資金順序**：現金（回調時壓到 10% 以下）→ 賣短債 → 股票質押／正 2 ETF；股市創高就調節，讓現金回到 15–20%。
6. **債券再平衡**：10 年期殖利率 ≥ 4.5% 加碼，維持股債約 8:2。

主力標的是美股 QQQ／SOXX，台股以 006208 為輔。

### 用現有資料試算的結果

以本站日 K 併成週 K、KD 參數 (9,3,3) 試算 J 值（他實際使用的參數未公開，這是假設），對照 2025 年以來的事件：

- **費半週 J 值與他的買點高度吻合**：#23、#24、#30、#34、#38、#40、#42、#44 進場時費半週 J 都 ≤ 25；#27、#28、#36（買債再平衡或調節股票）則落在 J > 100。
- **台股週 J 值較不敏感**：多數買點時台股 J 仍在 50 以上，只有 2025/4 與 2026/11 兩次大跌同步到 0 附近，符合他「主力看 SOXX／QQQ，台股為輔」的做法。
- **例外是小量買入**：#32、#33、#37 進場時 J 在 85 以上，屬於跌破季線或第一個 5% 跌幅觸發，不是週乖離訊號。
- 截至 2026/11/16：台股週 J 15.1、距 52 週高點 −17.9%；費半週 J 5.3、−30.8%；CNN 37.9。三項都在他的買進區，但距離目標跌幅（台股 30%、SOXX 55%）還有空間，與 #46「觀望、等破底」一致。

### 建議的併入順序

1. 週 J 值（加權、費半）＋ 自高點跌幅：現有資料即可算，訊號價值最高。
2. 綜合燈號：J < 25、CNN < 40、融資維持率 < 150%、跌幅級距，各自亮燈並標出命中幾項。
3. 把 `events.json` 的標記疊到加權指數 K 線上（即原 HTML 的進出圖）。
4. 新增資料源：QQQ／SOXX／006208 價格、`^TNX`、`^VIX`（Yahoo，與現有抓法相同）。
5. 月頻總經：景氣燈號、PMI、領先指標（來源與格式需另外確認）。
